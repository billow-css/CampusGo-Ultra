# Agenda · 时段计划

Agenda 是 CampusGo Ultra 的原生 macOS 模块，通过同一模块接口接入顶栏、摘要卡片和课表日期标记。按时段管理学习、工作与生活的任务清单，支持灵活调整。

## 使用

页面保持稳定的双栏工作区：顶部是独立的当前 / 下一段提醒，左侧是色块周历和待安排池，右侧始终展示选中时段的任务。

1. 单击周历色块只选择时段，不创建数据或占用编号；右侧可以直接输入。
2. 输入任务后按回车，加入清单并继续输入下一项。第一项任务提交或拖入后才创建安排并分配八位 S 编号。无需进入或完成编辑。
3. 已有任务可直接勾选和修改文字，自动保存。首项提交前的输入也按时段保存在本机，切换后可以继续写。
4. 待安排池中的任务可拖到任何时段，也可点击加号加入选中时段。任务行左侧拖动柄可移动任务到其他时段或移回池中。移动保留任务 UUID，不复制条目；已完成任务需要先取消勾选才能放回待安排池。
5. 逾期安排通过周历下方“待调整”入口查找；选中后可在右侧菜单顺延未完成项、移入待安排或删除整段。色块右键菜单也提供这些操作。
6. 删除整段后可以在顶部撤销，恢复编号、任务、勾选状态与输入草稿。

按 **Esc** 取消选择；按回车可聚焦选中时段的输入行。选中安排且未输入文字时，按 **⌫** 删除整段并可撤销；输入框内的退格键正常删除文字。

周历保留 M / A / N 三行，空段为中性色，任务越多绿色越深。非当天为正方形，当天适度加宽显示编号和任务数量；完整内容统一在右侧查看。

## 自定义标签页名称

在 **发现 → Agenda → 设置** 中修改“顶栏名称”，即时生效并在重启后保留；留空或点击“恢复默认”使用 Agenda。名称最多 120 个字符，超长名称在顶栏的固定宽度内往返滚动，鼠标悬停可查看完整名称。启用系统“减少动态效果”时使用省略显示。

名称设置独立于日程数据，时段、编号、任务清单与任务池不变；模块在发现页仍以 Agenda 标识。

## 时间规则

| 段 | 时间 | 归属 |
| --- | --- | --- |
| M | 07:00–12:00 | 当天 |
| A | 14:00–19:00 | 当天 |
| N | 19:00–次日 02:00 | 开始的那一天 |

采用本机日历与时区。边界为左闭右开，例如 19:00 属于 N，凌晨 02:00 不属于 N。02:00–07:00、12:00–14:00 是空档。

登机牌优先显示有未完成任务的当前段，其次未来最近一段；仅剩逾期任务时显示最近的逾期段。其他逾期任务始终可以从待处理列表进入。选中历史或未来格后，登机牌显示该格，点击“返回当前安排”退出手动选择。

## 顺延与编号

- 只移动未完成条目，已完成记录留在原段。
- 顺延到下一段；如果已经过去多天，会跳过已经结束的段，进入当前可用段或最近未来段。
- 目标已有安排时合并条目，并使用目标时段编号。
- 整段移动到空白目标且没有已完成条目、未提交草稿时，保留原时段编号。
- 部分移动到空白目标时，原段保留完成记录和原编号，目标分配新编号；每个子任务的 UUID 始终保持不变。
- 使用过的时段编号保留在已用集合中，不因空段移除而回收。
- 没有任务、只有草稿的段不算日程计划；完成编辑后的全空白段会移除。

## 联动与外观

- 沿用主应用的中性背景与登机牌卡片样式，固定草绿色强调色，同时适配浅色和深色模式。
- 课表日期左侧显示绿点，浅绿 / 绿色 / 深绿分别表示当天有 1 / 2 / 3 段安排。完成后保留标记；凌晨仍按 N 段开始日统计。
- 摘要卡片显示当前或下一段、进度、逾期待处理数量和池中数量。
- 首次引入模块时默认启用并固定到摘要。移出摘要后重启不会重新固定。
- 关闭模块隐藏顶栏入口、课表圆点及摘要卡片，保留计划数据。

## 存储与边界

计划以 `SciDocument` schema version 1 保存，使用模块作用域 `campus.gosci`、键 `plan.v1`，与课表快照分开。任务、完成状态、草稿、任务池及已用编号本地持久化；输入采用 250ms 合并保存，完成编辑、离开页面、关闭模块或正常退出应用时立即提交保存。

当前不接入 iCloud、WidgetKit、系统通知或主课表 JSON 备份导入导出；恢复课表备份不会覆盖 Agenda 数据。未来应通过版本化的模块数据导出接口统一备份。遇到格式损坏或未来版本的数据，禁止自动覆盖原值。

`Shared/GoSci.swift` 提供不依赖 SwiftUI 的时段、计划、任务与调整操作；`App/GoSciStore.swift` 管理独立存储和模块适配；`App/GoSciViews.swift` 提供完整页面及摘要卡片。核心测试覆盖午夜与时段边界、唯一编号、草稿恢复、进度、逾期、顺延合并、池移动和数据校验。

新工作区的未提交时段输入使用模块作用域 `slot-input.*` 键保存；待安排池输入使用 `pool-input.v1`。这些草稿不创建时段或分配编号，既有 `plan.v1` 及名称偏好保持兼容。
